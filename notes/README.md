# notes/

笔记 — all notes live here, organized by two orthogonal axes:

```
notes/
├── research/    # 常规：按主题组织的研究笔记（情绪、记忆、人格、创伤、伦理…）
└── periods/     # 时期：按时间组织的日志（年/月/日），记录当下思考与进展
```

- **research/**：面向"知识的沉淀"——理论、文献综述、设计 spec、架构蓝图。按主题建子目录，如 `emotion/`、`memory/`、`trauma/`、`ethics/`。
- **periods/**：面向"时间线"——每天/每时期的想法、实验记录、进展与挫折，命名 `年/月/日`（如 `2026/08/01.md`），也可以向上归纳为周记、月记。
