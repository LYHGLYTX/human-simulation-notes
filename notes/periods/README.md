# periods/

时期日志 — time-ordered journal entries.

按时间记录当下：每天的想法、实验进展、阅读随想、情绪观察、问题与顿悟。

**命名规则**：`年/月/日` 三级目录，当日笔记为 Markdown 文件：

```
periods/
└── 2026/
    └── 08/
        └── 01.md      # 2026-08-01 的日志
```

约定：

- 一篇日志 = 一个文件，文件名 `DD.md`（或 `DD-主题.md` 当一天多篇时）
- 内容自由：可以是一句话，也可以是长文
- 每月底可写 `monthly.md` 总结；年底可写 `yearly.md`
- 日志是"时间线"，主题知识请沉淀到 `../research/`
