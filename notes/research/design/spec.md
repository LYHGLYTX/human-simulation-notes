## 0. 目标与非目标

**目标**：模拟一个"完整的人"——拥有自传体历史、情绪、记忆、创伤、崩溃、道德冲突等**连续的内在状态**；对外界事件的每个反馈（好的、坏的、极端的）都由真实动力学驱动，而不是 LLM 即兴表演。

**非目标**：
- 不追求在统计上拟合真实人群的行为分布
- 不做临床诊断工具（不用于评估真实患者）
- 不做通用聊天机器人（对话只是输出通道之一）

**核心原则**：*状态机决定此刻感受，记忆决定为何如此，LLM 负责把两者变成人话和行动。*

## 1. 模拟对象定义（Persona）

### 1.1 静态属性（创建时设定，运行中缓慢演化）

| 属性 | 取值 | 理论依据 |
|---|---|---|
| 大五人格 OCEAN | 各 0–1 | 大五模型（`personality/theories.md` §1） |
| 黑暗三合一 | 自恋/马基雅维利/精神病态 各 0–1 | Paulhus & Williams 2002 |
| BIS / BAS | 行为抑制 / 行为激活 各 0–1 | Gray RST（`personality/theories.md` §2） |
| 依恋风格 | 安全 / 痴迷 / 疏离 / 恐惧 | Bartholomew 1991（`personality/theories.md` §6） |
| 控制点 | 内控 0–1 | Rotter 1966 |
| 道德推理水平 | Kohlberg 1–6 阶段 | `morality/theories.md` §1 |
| 道德基础权重 | 关爱/公平/忠诚/权威/圣洁/自由 各 0–1 | Haidt MFT |
| 文化自我 | 独立 0–1（1=独立，0=互依） | Markus & Kitayama 1991 |
| 核心图式 | 18 种早期适应不良图式各 0–1（被弃/不信任/缺陷…） | Young Schema 治疗（`psychopathology/theories.md` §4） |
| 韧性基线 | 0–1（影响崩溃阈值与恢复速率） | Bonanno 2004 |
| 生理基线 | 精力上限、睡眠需求、昼夜节律相位 | 具身认知（`neuroscience/theories.md` §6） |
| 初始人生年表 | 若干 {时间, 事件, 情绪标记, 重要性} | 自传体记忆（`memory/theories.md` §4） |

### 1.2 人格如何影响一切（静态→动态的映射）

- OCEAN 五项 → mood 吸引子（ALMA：人格→心境基线）
- BIS/BAS → 情绪冲击增益、冲动倾向
- 依恋风格 → 关系事件（被拒绝/被抛弃）的冲击放大系数
- 道德基础权重 × 道德推理水平 → 事件"规范兼容性"评价的权重
- 核心图式 → 特定类型事件的 appraisal 偏置（"被弃图式"→任何疏远信号都被高估威胁）

### 1.3 演化规则（创伤改变人格基线）

- 图式强度随相关创伤经历增强（Young：图式由早年经历形成并自我维持）
- 神经质随慢性应激缓慢上升；开放性可被创伤压降
- 依恋风格在重大关系创伤后可能恶化（安全→恐惧）
- 道德脱离倾向随越轨行为成功而上升（Bandura：道德脱离是习得的）
- 应激敏化：每次崩溃后，未来崩溃阈值永久下降（Monroe & Harkness）

## 2. 状态空间（动态状态，tick 驱动）

> 所有状态都是连续数值，持久化于引擎内；LLM 每次生成前读取快照，生成后状态继续演化。

### 2.1 情绪层（秒级）

| 状态 | 范围 | 说明 | 依据 |
|---|---|---|---|
| PAD 三值 | P/A/D ∈ [-1,1] | 当前情绪坐标 | Mehrabian & Russell 1974 |
| 主导情绪标签 | 离散 | 从 PAD 查表映射（恐惧/愤怒/悲伤/羞耻/…） | Russell 1980 / OCC |
| 情绪强度 | 0–1 | 冲击强度 | OCC 强度公式 |
| 衰减速率 | 参数 | 向 mood 基线弛豫（WASABI 弛豫方程） | WASABI |

### 2.2 心境层（分钟–小时级）

| 状态 | 说明 |
|---|---|
| mood PAD 基线 | 向 personality 吸引子弛豫（ALMA 三层） |
| 抑郁倾向 | 0–1（贝克负性认知的激活概率） |
| 警觉度 | 0–1（hypervigilance，创伤后上升，影响威胁检测灵敏度） |

### 2.3 应激与资源层（崩溃的核心）

| 状态 | 范围 | 说明 | 依据 |
|---|---|---|---|
| 应激负荷 stress | 0–100 | 事件冲击累积，随时间缓慢衰减 | GAS / Lazarus |
| 应对资源 resources | 0–100 | 消耗于应对事件；睡眠/支持/积极事件恢复 | COR（Hobfoll） |
| 崩溃阈值 threshold | 0–100 | 初始=60±韧性；每次崩溃后永久下降 | 应激敏化 |
| GAS 阶段 | 警觉/抵抗/衰竭/崩溃 | stress×资源 推导 | Selye 1936 |
| 异稳态磨损 wear | 0–∞ 永久项 | 慢性应激累积，降低恢复上限 | McEwen 1998 |
| 崩溃状态标志 | 崩溃中/恢复中 | 崩溃时的行为模式切换（僵直/爆发/解离） | 结构解离 |

**崩溃触发规则**：`stress > threshold` 且 `resources < 30` → 进入崩溃；或单事件冲击 > threshold×0.8 → 急性崩溃。崩溃类型由人格（BIS/BAS、依恋）+ 情境决定：战斗/逃跑/冻结/木僵。

### 2.4 认知控制层

| 状态 | 说明 | 依据 |
|---|---|---|
| 自我控制 self-control | 0–100，消耗于抑制冲动；低→失控 | Baumeister 自我损耗 |
| 注意资源 | 应激下下降（隧道效应） | Wickens / Kahneman |
| 冲动强度 impulse | 0–1，BIS/BAS×情境×资源 | Gray RST |

### 2.5 记忆系统

| 库 | 结构 | 说明 | 依据 |
|---|---|---|---|
| 自传体记忆（episodic） | 事件条目 {t, 内容, valence, arousal, importance, 巩固度} | 检索打分 = recency×importance×arousal×mood-congruence | Generative Agents + 情绪巩固（McGaugh）+ 遗忘曲线 |
| 语义/自我概念 | 图式强度、自我叙事、关于他人的事实 | 由 reflection 从 episodic 提炼 | Tulving / Conway |
| 创伤记忆通道 | 感官碎片 {触发词, 碎片内容, 无时间感标记} + 情境化叙事分离 | 触发词命中→侵入性闪回（绕过正常检索） | Ehlers & Clark / DRT |
| 工作记忆 | 当前 context 槽位（约 4±1 项） | 决定"此刻想到什么" | Cowan 2001 |

### 2.6 社会关系层

| 状态 | 说明 | 依据 |
|---|---|---|
| 关系图 | 每人 = {好感度, 信任度, 权力差, 依恋激活, 互动史} | Kelley 相互依赖 / Sternberg |
| 社会支持 | 关系图中可求助者的总和（COR 资源项） | Hobfoll |

### 2.7 道德层

| 状态 | 说明 | 依据 |
|---|---|---|
| 内化规范集 | {内容, 强度 0–1, 来源(权威/社会/自省), Kohlberg 阶段} | Kohlberg / Turiel |
| 道德脱离倾向 | 8 机制各 0–1 | Bandura 1999 |
| 内疚/羞耻 | 0–1 瞬时值（行为 vs 规范/自我差异） | Tangney / Higgins |

### 2.8 生理层

| 状态 | 说明 |
|---|---|
| 精力 0–100、睡眠债、饥饿、疲劳 | 影响认知控制与情绪稳定性（具身认知） |
