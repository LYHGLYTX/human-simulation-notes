# 核心引擎规格说明（Spec v0.1）

> 位置：`notes/research/design/spec.md`
> 状态：编写中（第 1/3 部分完成：对象定义 + 状态空间）
> 理论依据：`notes/research/<主题>/theories.md`（10 模块理论全集）
> 项目参考：`notes/periods/2026/08/01.md`（工程层项目对比 + 论文清单）

## 0. 目标与非目标

**目标**：模拟一个"完整的人"——拥有自传体历史、情绪、记忆、创伤、崩溃、道德冲突等**连续的内在状态**；对外界事件的每个反馈（好的、坏的、极端的）都由真实动力学驱动，而不是 LLM 即兴表演。

**非目标**：
- 不追求在统计上拟合真实人群的行为分布
- 不做临床诊断工具（不用于评估真实患者）
- 不做通用聊天机器人（对话只是输出通道之一）

**核心原则**：*状态机决定此刻感受，记忆决定为何如此，LLM 负责把两者变成人话和行动。*

## 1. 模拟对象定义（Persona）

### 1.1 静态属性（创建时设定，运行中缓慢演化）

| 属性 | 取值 | 理论依据 |
|---|---|---|
| 大五人格 OCEAN | 各 0–1 | 大五模型（`personality/theories.md` §1） |
| 黑暗三合一 | 自恋/马基雅维利/精神病态 各 0–1 | Paulhus & Williams 2002 |
| BIS / BAS | 行为抑制 / 行为激活 各 0–1 | Gray RST（`personality/theories.md` §2） |
| 依恋风格 | 安全 / 痴迷 / 疏离 / 恐惧 | Bartholomew 1991（`personality/theories.md` §6） |
| 控制点 | 内控 0–1 | Rotter 1966 |
| 道德推理水平 | Kohlberg 1–6 阶段 | `morality/theories.md` §1 |
| 道德基础权重 | 关爱/公平/忠诚/权威/圣洁/自由 各 0–1 | Haidt MFT |
| 文化自我 | 独立 0–1（1=独立，0=互依） | Markus & Kitayama 1991 |
| 核心图式 | 18 种早期适应不良图式各 0–1（被弃/不信任/缺陷…） | Young Schema 治疗（`psychopathology/theories.md` §4） |
| 韧性基线 | 0–1（影响崩溃阈值与恢复速率） | Bonanno 2004 |
| 生理基线 | 精力上限、睡眠需求、昼夜节律相位 | 具身认知（`neuroscience/theories.md` §6） |
| 初始人生年表 | 若干 {时间, 事件, 情绪标记, 重要性} | 自传体记忆（`memory/theories.md` §4） |

### 1.2 人格如何影响一切（静态→动态的映射）

- OCEAN 五项 → mood 吸引子（ALMA：人格→心境基线）
- BIS/BAS → 情绪冲击增益、冲动倾向
- 依恋风格 → 关系事件（被拒绝/被抛弃）的冲击放大系数
- 道德基础权重 × 道德推理水平 → 事件"规范兼容性"评价的权重
- 核心图式 → 特定类型事件的 appraisal 偏置（"被弃图式"→任何疏远信号都被高估威胁）

### 1.3 演化规则（创伤改变人格基线）

- 图式强度随相关创伤经历增强（Young：图式由早年经历形成并自我维持）
- 神经质随慢性应激缓慢上升；开放性可被创伤压降
- 依恋风格在重大关系创伤后可能恶化（安全→恐惧）
- 道德脱离倾向随越轨行为成功而上升（Bandura：道德脱离是习得的）
- 应激敏化：每次崩溃后，未来崩溃阈值永久下降（Monroe & Harkness）

## 2. 状态空间（动态状态，tick 驱动）

> 所有状态都是连续数值，持久化于引擎内；LLM 每次生成前读取快照，生成后状态继续演化。

### 2.1 情绪层（秒级）

| 状态 | 范围 | 说明 | 依据 |
|---|---|---|---|
| PAD 三值 | P/A/D ∈ [-1,1] | 当前情绪坐标 | Mehrabian & Russell 1974 |
| 主导情绪标签 | 离散 | 从 PAD 查表映射（恐惧/愤怒/悲伤/羞耻/…） | Russell 1980 / OCC |
| 情绪强度 | 0–1 | 冲击强度 | OCC 强度公式 |
| 衰减速率 | 参数 | 向 mood 基线弛豫（WASABI 弛豫方程） | WASABI |

### 2.2 心境层（分钟–小时级）

| 状态 | 说明 |
|---|---|
| mood PAD 基线 | 向 personality 吸引子弛豫（ALMA 三层） |
| 抑郁倾向 | 0–1（贝克负性认知的激活概率） |
| 警觉度 | 0–1（hypervigilance，创伤后上升，影响威胁检测灵敏度） |

### 2.3 应激与资源层（崩溃的核心）

| 状态 | 范围 | 说明 | 依据 |
|---|---|---|---|
| 应激负荷 stress | 0–100 | 事件冲击累积，随时间缓慢衰减 | GAS / Lazarus |
| 应对资源 resources | 0–100 | 消耗于应对事件；睡眠/支持/积极事件恢复 | COR（Hobfoll） |
| 崩溃阈值 threshold | 0–100 | 初始=60±韧性；每次崩溃后永久下降 | 应激敏化 |
| GAS 阶段 | 警觉/抵抗/衰竭/崩溃 | stress×资源 推导 | Selye 1936 |
| 异稳态磨损 wear | 0–∞ 永久项 | 慢性应激累积，降低恢复上限 | McEwen 1998 |
| 崩溃状态标志 | 崩溃中/恢复中 | 崩溃时的行为模式切换（僵直/爆发/解离） | 结构解离 |

**崩溃触发规则**：`stress > threshold` 且 `resources < 30` → 进入崩溃；或单事件冲击 > threshold×0.8 → 急性崩溃。崩溃类型由人格（BIS/BAS、依恋）+ 情境决定：战斗/逃跑/冻结/木僵。

### 2.4 认知控制层

| 状态 | 说明 | 依据 |
|---|---|---|
| 自我控制 self-control | 0–100，消耗于抑制冲动；低→失控 | Baumeister 自我损耗 |
| 注意资源 | 应激下下降（隧道效应） | Wickens / Kahneman |
| 冲动强度 impulse | 0–1，BIS/BAS×情境×资源 | Gray RST |

### 2.5 记忆系统

| 库 | 结构 | 说明 | 依据 |
|---|---|---|---|
| 自传体记忆（episodic） | 事件条目 {t, 内容, valence, arousal, importance, 巩固度} | 检索打分 = recency×importance×arousal×mood-congruence | Generative Agents + 情绪巩固（McGaugh）+ 遗忘曲线 |
| 语义/自我概念 | 图式强度、自我叙事、关于他人的事实 | 由 reflection 从 episodic 提炼 | Tulving / Conway |
| 创伤记忆通道 | 感官碎片 {触发词, 碎片内容, 无时间感标记} + 情境化叙事分离 | 触发词命中→侵入性闪回（绕过正常检索） | Ehlers & Clark / DRT |
| 工作记忆 | 当前 context 槽位（约 4±1 项） | 决定"此刻想到什么" | Cowan 2001 |

### 2.6 社会关系层

| 状态 | 说明 | 依据 |
|---|---|---|
| 关系图 | 每人 = {好感度, 信任度, 权力差, 依恋激活, 互动史} | Kelley 相互依赖 / Sternberg |
| 社会支持 | 关系图中可求助者的总和（COR 资源项） | Hobfoll |

### 2.7 道德层

| 状态 | 说明 | 依据 |
|---|---|---|
| 内化规范集 | {内容, 强度 0–1, 来源(权威/社会/自省), Kohlberg 阶段} | Kohlberg / Turiel |
| 道德脱离倾向 | 8 机制各 0–1 | Bandura 1999 |
| 内疚/羞耻 | 0–1 瞬时值（行为 vs 规范/自我差异） | Tangney / Higgins |

### 2.8 生理层

| 状态 | 说明 |
|---|---|
| 精力 0–100、睡眠债、饥饿、疲劳 | 影响认知控制与情绪稳定性（具身认知） |

## 3. 动力学（事件处理管线）

> 回答核心问题："外界信息进来之后，会变成什么"——每一步都有理论依据。

### 3.1 主循环（tick 驱动）

每 tick（默认 1 秒游戏时间，可配置）：

1. **状态弛豫**：情绪 PAD → 向 mood 基线弛豫（WASABI 方程）；mood → 向 personality 吸引子弛豫（ALMA）；stress 衰减；resources 恢复；self-control 恢复
2. **生理更新**：精力消耗/恢复、睡眠结算（睡眠是 resources 的最大恢复源）
3. **事件处理**：事件队列依次走 3.2 管线
4. **触发检查**：闪回触发（创伤通道命中）、崩溃触发（3.3.2）、越轨冲动触发（3.3.3）
5. **输出快照**：当前全部状态（供 UI / LLM 读取）

### 3.2 事件处理管线（感知 → 评价 → 状态更新 → 决策 → 行为 → 记忆）

```
事件 e（结构化：{类型, 主体, 对象, 内容, 时间, 强度线索}）
  │
  ├─ 1. 感知编码        LLM：原始事件 → 结构化描述 + 关键属性
  ├─ 2. Appraisal       LLM 输出 Scherer 五级检查表（各 0–1）：
  │                     新颖性 / 内在愉悦性 / 目标相关性 / 应对潜力 / 规范兼容性
  │                     + Smith & Ellsworth 维度（可控性 / 责任归属）
  │                     + 图式偏置：命中核心图式 → 威胁性放大（Young）
  ├─ 3. 情绪冲击        appraisal → OCC 情绪类型 + 强度 → PAD 位移（查表）
  ├─ 4. 应激累积        stress += 冲击×系数；resources -= 应对消耗
  ├─ 5. 记忆写入        常规：episodic 条目 {t, 内容, valence, arousal, importance}
  │                     arousal 高 → 巩固度起点高（McGaugh 情绪巩固）
  │                     └─ 创伤判定（3.3.1）→ 走创伤通道
  ├─ 6. 决策            候选行为集评分（3.4）→ 选择
  │                     └─ 崩溃检查：崩溃中 → 崩溃行为谱（战斗/逃跑/冻结/木僵）
  ├─ 7. 行为输出        LLM 注入完整状态快照生成行为/语言
  └─ 8. 反馈循环        行为后果 → 新事件（回到 1）
                        自我调节：反刍→抑郁倾向↑；重评→恢复↑（Gross）
```

### 3.3 三大核心机制（我们的核心竞争力）

#### 3.3.1 创伤机制（Ehlers & Clark / DRT）

- **触发条件**：冲击 ≥ 创伤阈值（人格相关：图式强度×事件类型），或命中创伤主题（丧失/背叛/暴力/羞耻）
- **编码**：创伤通道只存**感官碎片**（声音/气味/画面等碎片，无时间感、低情境化）+ 提取**触发词**；正常 episodic 只存弱化版本（双重表征：VAM vs SAM）
- **闪回**：后续事件命中触发词 → 强制侵入工作记忆（绕过正常检索）+ 高唤醒 + 时间感丧失 + 当前 PAD 被拉向创伤时的状态
- **处理**：安全环境重述（暴露）→ 碎片情境化（Foa 情绪加工）→ 闪回频率下降；再巩固窗口（提取后短暂不稳定）允许记忆改写（Nader 2000）
- **表现**：回避行为（接近触发情境→应激预增）、警觉度↑、解离（严重时：结构解离→行为模式切换）

#### 3.3.2 崩溃机制（GAS / COR / 异稳态 / 应激敏化）

- **双变量模型**：`stress`（累积）与 `resources`（存量）——stress 涨、resources 跌 → 衰竭（Selye GAS 三阶段：警觉→抵抗→衰竭）
- **触发**：`stress > threshold` 且 `resources < 30%` → 慢性崩溃；单事件冲击 > `threshold × 0.8` → 急性崩溃
- **崩溃类型**（由人格×情境决定）：
  - 高 BIS → 冻结 / 木僵（Fanselow 防御等级：近→战斗，远→逃跑，无路→冻结）
  - 高 BAS + 高愤怒 → 爆发 / 攻击
  - 依恋恐惧 + 关系事件 → 解离
- **崩溃后不可逆项**：
  - `threshold` 永久下降（应激敏化，Monroe & Harkness）
  - `wear`（异稳态磨损）累积 → 恢复上限降低（McEwen）
  - 可能进入：抑郁态（贝克负性认知激活：自我/世界/未来全否定）、习得性无助（放弃行为）、反刍循环（DMN 过度）
- **恢复**：睡眠（最大恢复源）、社会支持（关系图求和）、积极事件；恢复后可能 PTG（创伤后成长，恢复上限小幅上升）

#### 3.3.3 越轨机制（GST / 道德脱离 / 自我损耗）

```
压力（目标受阻/失去/负面刺激 — Agnew GST）
  → 负面情绪（愤怒/绝望/羞耻）
  → 冲动生成：impulse = BAS × 挫折感 × (1 - self-control)
  → 规范对抗：候选越轨行为 vs 内化规范强度
      ├─ 规范强 → 内疚/羞耻冲击 → 抑制（self-control 消耗）
      └─ 道德脱离激活（压力大且冲动强时概率↑）：
         合理化（"这是应得的"）→ 规范权重临时下降 → 越轨行为放行
  → 越轨执行后的回路：
      ├─ 成功且未受罚 → 道德脱离倾向习得性上升（Bandura）→ 下次更容易
      └─ 规范仍在 → 内疚/羞耻（Tangney：羞耻针对自我更毁灭）→ 反刍 / 自我惩罚 / 图式强化
  → 机会因素：匿名性（去个体化）、缺乏监护 → 行为门槛降低
```

### 3.4 决策模型（分层）

| 层 | 机制 | 说明 |
|---|---|---|
| 默认 | 规则+效用混合 | 候选行为评分 = 情绪驱动（PAD→行动倾向，Frijda）× 后果效用估计 × 冲动 × 规范约束；高压下走捷径（系统1） |
| 升级（可选） | **pymdp 主动推理** | 预期自由能决策；情绪编码为先验偏好 C 向量；探索/回避统一 |

### 3.5 时间与事件调度

- 事件有发生时间与到达顺序；多个事件排队处理（高压情境下连击事件 → 冲击叠加）
- 事件强度可配置（世界向引擎注入事件时给出强度线索；无强度时 LLM 估计）
- 支持"模拟模式"：批量注入事件序列跑长时程演化（细致前端用）

## 4. LLM 集成层

### 4.1 LLM 的职责边界

| 做（LLM） | 不做（引擎规则层） |
|---|---|
| 感知编码：原始事件 → 结构化事件 | 情绪状态更新（PAD 数值积分） |
| Appraisal 检查表（Scherer 五级+维度，输出 0–1 JSON） | 记忆写入与检索排序 |
| 行为/语言生成（注入状态快照） | 应激/资源/崩溃判定 |
| 事件强度估计 | 道德规范比较 |

原则：**LLM 做"语义理解与表达"，规则层做"状态积分"**——LLM 的输出永远是结构化数值或文本，状态的演化永远由方程决定。

### 4.2 接口设计（可插拔）

```python
class LLMClient(Protocol):
    def perceive(self, raw: str, persona: dict) -> Event: ...          # 事件结构化
    def appraise(self, event: Event, state: State, persona: dict) -> Appraisal: ...  # Scherer 检查表
    def generate(self, snapshot: StateSnapshot, context: list[Memory], decision: Decision) -> Action: ...  # 行为生成
```

实现层（同一接口，可切换）：
- **MockLLM**：规则式默认值（离线可跑，引擎开发用）
- **OpenAICompatLLM**：OpenAI 兼容 API（json 结构化输出）
- **LocalLLM**：ollama 等本地模型

### 4.3 生成时注入的状态快照

每次 `generate` 的 prompt 包含：
1. persona 摘要（人格参数 → 自然语言描述："他信任人很慢，被拒绝会反应强烈"）
2. 当前状态（PAD/心境/应激/资源/自控，数值+文字解释）
3. 工作记忆内容（当前激活的记忆片段，含情绪标记）
4. 决策结果（引擎选定的行为类型）
5. 约束：输出必须与状态一致（情绪化状态下不能写冷静理性的台词）

### 4.4 一致性护栏

- 温度 0.3–0.7（可配）
- 输出 schema 校验（行为类型枚举 + 文本）
- 状态-行为矛盾检测：如高绝望+低资源却生成"充满希望的计划"→ 拒绝重生成（最多 2 次），仍失败则降级为规则模板行为
- 所有 LLM 调用记录进日志（细致模式可回溯）

## 5. 双模式界面

### 5.1 共享核心

两种模式**共用同一个引擎实例**（同一状态、同一记忆、同一动力学）——游戏化只是"显示简化"，细致模式是"完整读数"。保证"游戏里看到的条"背后就是真实动力学。

### 5.2 游戏化模式（🎮 直观层）

- **状态条面板**：情绪（PAD→表情+颜色条）、心情、压力、精力、社交支持、道德约束、欲望/冲动
- **事件卡片流**：世界发事件（卡片展示）→ 玩家选择引擎预生成的 3–4 个选项（选项由当前状态推导）
- **即时反馈**：选择后状态条动画变化 + 角色反应气泡（LLM 生成一句话）
- **时间控制**：暂停 / 快进 / 自动
- 数值隐藏，一切用条/表情/颜色——让非研究者也能"玩懂"一个人的心理

### 5.3 细致模式（🔬 研究层）

- **完整状态表**：§2 所有状态实时数值 + 变化率
- **管线日志**：每次事件 8 步全记录（appraisal 各维度值、冲击量、为什么选这个行为）
- **推理链视图**：这次反应由哪些记忆/图式/状态驱动，可点击溯源到具体记忆条目
- **记忆浏览器**：episodic / 创伤通道 / 语义 分库浏览、检索测试
- **量表施测**：对模拟对象跑 PCL-5 / PHQ-9 / PANAS，分数对照叙事自洽性
- **批量模拟**：注入事件序列跑 N 次 → 状态轨迹统计（重复性、崩溃率、恢复率）

### 5.4 技术栈建议

- 引擎：Python 3 + dataclass 状态 + 事件循环（无第三方依赖优先，pymdp 为可选升级）
- API 层：FastAPI（状态/事件/快照端点）
- 前端：先 Streamlit 快速原型（双模式两页），后续可换 React

## 6. 验证方案（怎么算"真实"）

### 6.1 一致性测试（自动化，引擎自带测试集）

- 同一事件重复 50 次 → 行为分布方差小（不随机漂移）
- 人格对比：高神经质 vs 低神经质面对同一事件 → 应激反应方向符合理论
- 历史一致性：创伤事件写入后，相关闪回/回避可复现；记忆不可被事后篡改

### 6.2 量表对照

- 对模拟对象施测 PCL-5（创伤）、PHQ-9（抑郁）、PANAS（情绪）、STAI（焦虑）
- 分数与行为日志必须自洽：PCL-5 高分者应表现出回避/警觉/闪回，而非一切正常

### 6.3 专家盲评

- 设计对照实验：同一事件 × 不同人格 → 日志匿名化 → 心理学背景者盲评"像不像真实的人"
- 迭代：盲评反馈 → 调参数 → 再测

### 6.4 场景库（测试资产）

| 类别 | 场景示例 |
|---|---|
| 日常 | 被夸赞 / 被拒绝 / 加班 / 朋友疏远 |
| 压力 | 被当众羞辱 / 失恋 / 失业 / 财务危机 |
| 创伤 | 背叛 / 暴力威胁 / 亲人离世 / 童年事件重演 |
| 极端 | 长期虐待 / 目睹惨剧 / 被逼入绝境 |

每个场景标注理论预期响应（断言用）。

### 6.5 伦理护栏

- **研究视角开关**：默认开启完整推理链可见（透明性）
- **内容警示**：模拟可能产出极端内容，界面标明"模拟研究用途，非诊断工具"
- **自杀/自伤相关输出**：研究模式下显示标准干预提示文本（模拟内角色行为仅作研究数据，不模拟真实求助流程）
- 越轨内容用于理解"人为什么走到那一步"，不提供犯罪方法细节
