# projects/

模拟程序的目录 — simulation programs, prototypes & agents.

这里存放所有**可运行的模拟程序**：人类精神状态模拟器、agent 原型、情绪状态机、记忆系统实现等。

每个项目自包含，拥有自己的 `README.md` 和运行说明：

```
projects/
├── <project-name>/
│   ├── README.md      # 项目说明、运行方式
│   ├── src/           # 源码
│   └── tests/         # 测试
```

命名建议：`kebab-case`（如 `trauma-agent/`、`emotion-core/`）。
